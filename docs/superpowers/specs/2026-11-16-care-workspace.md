# CareRoute expanded workspace design

The user requests a more attractive official-looking product, light/dark themes, a public explanation of patient/doctor/coordinator responsibilities, doctor prescription authoring, first-aid information, Pune healthcare listings, independent branding and market readiness without false claims.

Continue the existing React/Capacitor product. Preserve working journey coordination. Use a teal/navy design, readable typography, consistent cards, stronger navigation and clear active states. Light/dark/system preferences persist across reloads. Mobile controls must remain usable.

Implement clinician-entered consultation notes and prescription drafts, visit preparation, queue and follow-up organisation, public searchable Pune listings, sourced adult first-aid references and an evidence-library page. Do not auto-generate medicines, doses, diagnoses or claims of comprehensive specialist knowledge. All prescription outputs remain unsigned demonstration drafts, require completeness review, and show the limitation in the document itself. Clinical decisions stay with a registered practitioner.

Source records must carry provenance and retrieval dates. Missing specialties are marked unknown. No invented ratings, appointments, doctor registration checks, availability or partnerships. A directory snapshot is not a complete census of Pune. First aid is educational with conspicuous emergency access and explicit adult scope; source lookup is not clinical validation.

Continue fictional, device-local data until real authentication/backend controls and institution-specific approvals exist. Additions must participate in deletion/reset and avoid implying real accounts or live medical service. Production readiness is a documented workstream, not a label added by UI changes. No AI training has occurred. A custom domain requires a user-owned domain; preserve existing private hosting access.

The implementation choices above are defaults within the user's authorised enhancement request. No new payment, domain purchase, outreach or external booking is authorised.
